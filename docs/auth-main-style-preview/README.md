# Main style login preview

The identity panel now uses the glass card, centered university logo, and dark blue gradient from the visual language of `main`. The phone-first form and pilot authentication contract are unchanged. The previous open-book illustration remains in the repository as unused design history.

`fa-375.png`, `fa-1280.png`, and `en-1280.png` were captured in headless Chromium from a local development server with `PHONE_AUTH_ENABLED=true`. The Next.js development indicator was hidden in the capture only. No backend response was needed for these initial-screen images. Width checks at 320, 375, 412, and 1280 CSS pixels showed no horizontal scrolling, and the primary mobile action was visible within the initial viewport. These captures are not tests on physical phones or a deployed backend.
