# Auth identity preview

These screenshots are a visual review of the new phone-first auth identity surface. They were captured from a local development build in headless Chromium, at CSS viewport widths of 375 and 1280 px. The registration screenshot uses a mocked `identify: register, verification_required: false` response. They are neither screenshots from staging nor tests on physical Android/iOS devices. The decorative illustration is an original open-book motif; it does **not** claim to depict the real university entrance.

`before-998eb8a-fa-375.png` and `before-998eb8a-fa-1280.png` show the identity panel as implemented at PR #132 head `998eb8a` before the corrective branch. The matching `login-fa-375.png` and `login-fa-1280.png` show the new design. `login-en-*` captures the English layout; `register-pilot-fa-375.png` captures the pilot's direct registration form.
